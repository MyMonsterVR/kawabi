# Code of Conduct

This is a small hobby project. People show up to fix a bug, add a feature,
or ask a question, and that's it — no company, no HR department, just
strangers on the internet helping each other out. Act like it:

- Be decent. Disagree about code all you want, don't be a jerk about it.
- Assume good faith. Most confusing PRs and blunt comments are just
  someone in a hurry, not someone out to get you.
- No harassment, hate speech, or personal attacks. Obvious stuff, but
  it's the one rule that actually matters.
- Keep discussion on-topic (issues, PRs, discussions) — this isn't the
  place for unrelated arguments.

If someone's being a problem, ping the maintainer directly or open an
issue. It'll get looked at and sorted out reasonably — no tribunal, no
formal process, just a judgment call.

That's it. Be cool, help each other out, ship good code.
